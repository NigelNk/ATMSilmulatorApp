JavaFX ATM Simulator

A simple JavaFX ATM simulator program built using IntelliJ IDEA and SceneBuilder.
This project demonstrates the use of JavaFX for creating a graphical user interface and simulating basic ATM functionalities such as account login, balance checking, deposits, and withdrawals.

Tools & Technologies
JavaFX — for the GUI
IntelliJ IDEA — for development
SceneBuilder — for UI layout design

JDK-21

Features

Account creation
User authentication (login screen)
Account balance display

Deposit and withdrawal simulation

Simple and intuitive GUI
